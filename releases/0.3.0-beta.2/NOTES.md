# ASTRA 0.3.0-beta.2

2026-10-10

## Novedades

- Notificaciones que no llegaban: Discord (y webs como WhatsApp Web) borran las suyas a los pocos segundos y en ASTRA se esfumaban. Ahora se quedan hasta que las descartes.
- Notificaciones: se leen las de apps con plantillas antiguas; al retirar el permiso en Windows la lista se vacía al momento; descartar refresca al instante.
- Actualizar: si el instalador no arranca, ASTRA sigue visible y con su icono en la bandeja; «Buscar» espera a una búsqueda en marcha en vez de decir «ocupado».
- Iniciar con Windows dice la verdad si lo apagaste en el Administrador de tareas, y encenderlo desde ASTRA vuelve a funcionar.
- Chat: respuestas largas sin cortar (el doble de espacio), el texto no te arrastra abajo mientras lees, y una acción detenida no se queda girando.
- Agentes: los ganchos de Codex y Cursor funcionan con nombres de usuario con &, ( ) o %.
- Desinstalar devuelve los avisos de Windows con ASTRA ya cerrada; el progreso de una actualización sigue al cambiar de página en Ajustes; y una veintena de arreglos más.

## What's new

- Notifications that never arrived: Discord (and web apps like WhatsApp Web) remove theirs after a few seconds, and in ASTRA they vanished. Now they stay until you dismiss them.
- Notifications: older toast templates are read too; taking the permission away in Windows empties the list at once; dismissing refreshes instantly.
- Updates: if the installer fails to start, ASTRA stays visible with its tray icon; “Check” waits for a check already running instead of saying “busy”.
- Start with Windows tells the truth when you switched it off in Task Manager, and switching it on from ASTRA works again.
- Chat: long answers no longer cut short (twice the room), the text does not drag you down while you read, and a stopped action does not spin for ever.
- Agents: Codex and Cursor hooks work with user names containing &, ( ) or %.
- Uninstalling restores Windows' banners with ASTRA already closed; an update's progress survives changing pages in Settings; and some twenty more fixes.
